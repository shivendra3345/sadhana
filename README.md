# Birthday Wish Site

This repository now contains a small static birthday wish site that can be
served directly by GitHub Pages or any static file server.

## Files

- `index.html` — single-page birthday wish site

## Run locally

Because the site is fully static, you can open `index.html` directly in a
browser or serve it with a simple HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
